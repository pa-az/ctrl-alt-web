What is Context Collapse?

Platforms merge family, colleagues, friends, and strangers into one audience. A post written for one group is easily misread by another, which generates conflict.

Where it comes from

Broadcast-Style Social Feeds (2000s)

How it hooks you

Exploits flattened audiences: removing context makes misunderstandings more likely, and misunderstandings generate high-engagement conflict.

How to resist it

Use different platforms for different social circles, or move conversations into private group chats.

Where you’ll run into it

  • Discord
  • Facebook
